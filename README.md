# BuildMaster Pro

Responsive construction-management starter for web and Android (installable PWA).

## Deploy with GitHub Pages
1. Open repository Settings → Pages.
2. Under Build and deployment, choose **Deploy from a branch**.
3. Select branch **main**, folder **/(root)**, then Save.
4. Wait for Pages to publish. Your site URL will be https://anthonynocash-stack.github.io/BuildMaster-Pro/.

## Run locally
Run `python -m http.server 8000` in this folder and open http://localhost:8000.

## Install on Android
After deploying over HTTPS, open the site in Chrome on Android and choose Install app or Add to Home screen.

## Included
Projects, Naira budgets, expenses, materials, workers, schedules, CSV reports, JSON backup/restore, responsive UI and a PWA service-worker shell.

## Important limitations
This is a starter prototype. Data is stored in the browser on each device and is not synchronized. It has no accounts, shared company workspace, cloud database, AI, push notifications, payroll, supplier integrations or background automation yet. Those require a secure backend and additional setup. Do not store sensitive personal or financial data in this prototype.
